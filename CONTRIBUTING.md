# Contributing to the Deep Logic Portfolio

We welcome contributions! This repository features **67** high-performance Rust services.

## Contribution Rules
1. **Async First**: Use tokio/async-await exclusively.
2. **Hexagonal Architecture**: Keep domain logic isolated from frameworks.
3. **No Python**: This is a Rust-only ecosystem. Do not add Python scripts.
4. **Star the Repo**: Help us grow by starring this repository!

## How to Submit
- Fork the repository.
- Create a feature branch.
- Submit a PR with a description of your optimization or fix.
- Ensure the project passes `cargo build`.
